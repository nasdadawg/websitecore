# CANTCLONE — Implementation Plan

v1-required only. Everything else is v1.1, later, or external-provider
— see PLATFORM-CHECKLIST.md. Dependency order below; each becomes one
Hermes task once approved, not before.

## Milestone 1 — Core data model & tenant security
Payload collections (Users, Tenants, Leads) with the multi-tenant
plugin wired correctly. Per-site secret generation and storage on the
Tenant document. No API route yet.

## Milestone 2 — Secure lead intake
`/api/leads` on cantclone-core: secret-based auth, Zod validation,
Upstash rate limiting, idempotency key, writes to Leads, `after()`
Resend notification. The single most important milestone — nothing
else matters if this isn't solid.

## Milestone 3 — Isolation verification
Two real tenant + user documents. Prove neither can see the other's
data via the admin panel and via the API directly. A test milestone —
produces evidence, not new UI.

## Milestone 4 — Admin panel basics
Confirm Payload's generated admin panel shows the right scoped leads
to a `client`-role user, and everything to an `agency-owner`-role user.

## Milestone 5 — One client site, wired end to end
Clone the frontend template for one real vertical (recommend PPF/
detailing). Its own `/api/submit-lead` route holding the site secret.
Real form, real design tokens, real copy — built manually in Claude
Code, not generated by a Hermes task.

## Milestone 6 — Turnstile + preview deploy
Bot protection on the public form. Vercel preview deployment working
for both repos.

## Milestone 7 — End-to-end real test
One real test lead through the actual deployed client site. Confirm
it lands in the admin panel and the notification email fires. This is
the acceptance gate for calling v1 done.

## Explicitly not in v1
Payments, Stripe Connect, SMS, Instagram DM sending, ManyChat, AI
autonomous messaging, full chatbot, Search Console OAuth, Google
Business Profile API, advanced SEO publishing, complex client billing.
None of these get a Hermes task until Milestone 7 passes.
